Duplicator desde archivos en disco

Para .daf grandes (varios GB). Sube los archivos por SFTP/SCP al servidor y el panel los mueve al docroot del sitio.

📋 Cómo subir los archivos
Carpeta recomendada: {{ default_dir }} — persistente, propietario appuser, fácil de limpiar.
Si estás en la red local
(misma LAN/WiFi que el server) — más rápido, no pasa por ZeroTier.
Host:
192.0.2.10
scp:
scp installer.php archive.daf \
  appuser@192.0.2.10:{{ default_dir }}/
Si estás fuera (vía ZeroTier)
Conecta primero a ZeroTier; luego usa la IP de la red ZT.
Host:
192.0.2.20
scp:
scp installer.php archive.daf \
  appuser@192.0.2.20:{{ default_dir }}/
Desde un cliente SFTP (Filezilla, Cyberduck):
  • Host: 192.0.2.10 (LAN) o 192.0.2.20 (ZeroTier)
  • Port: 22
  • User: appuser · key o password de SSH
  • Carpeta destino: {{ default_dir }}/
Otras carpetas válidas: cualquier subdir de /tmp/ o /home/appuser/. Tip: /tmp/ se vacía al reiniciar el server. Si quieres conservar archivos entre reboots, usa /home/appuser/.
